# HR-scoring

Веб-приложение на Flask для прескоринга кандидатов: сравнение резюме и вакансии с помощью LLM (OpenAI) и выдача оценки соответствия.

## Возможности
- Ввод данных в интерфейсе:
  - **Текстовый режим**: вставить текст вакансии и текст резюме.
  - **Режим ссылок (HH)**: вставить ссылки на страницы вакансии/резюме HH.ru (best-effort).
  - **Auto**: если оба поля похожи на ссылки — пытается парсить HH, иначе обрабатывает как текст.
- Скоринг кандидата:
  - краткий анализ (пояснение оценки),
  - оценка качества резюме (1–10),
  - оценка соответствия вакансии (1–10).
- Для режима ссылок показывает распарсенный текст (для проверки).

## Ограничения
- HH.ru может возвращать **403 Forbidden** (часто для резюме — требуется авторизация или срабатывает антибот).
  - В этом случае используйте **текстовый режим**: вставьте данные вручную.

## Технологии
- Python 3.10+
- Flask
- OpenAI SDK
- requests + BeautifulSoup4
- gunicorn (для деплоя)

## Локальный запуск

### 1) Установка зависимостей
pip install -r requirements.txt

### 2) Переменные окружения
Создайте файл .env в корне проекта:
OPENAI_API_KEY=sk-...

### 3) Запуск
python app.py
Откройте в браузере:
http://127.0.0.1:5000
Запуск в продакшене (пример)
gunicorn app:app --bind 0.0.0.0:8000

### Структура проекта
app.py — Flask-приложение и логика запроса к модели
hh_parser.py — загрузка HTML и извлечение данных вакансии/резюме
templates/index.html — интерфейс (форма + вывод результатов)
requirements.txt — зависимости

### Формат ответа модели
Анализ (3–7 пунктов)
Качество резюме: X/10
Соответствие вакансии: Y/10
